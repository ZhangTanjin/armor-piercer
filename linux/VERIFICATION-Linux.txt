四、fuse_round.py 与 apply_fusion.ps1 等价性
----------------------------------------------
命令: python fuse_round.py armor_payload.pre-fusion.bin .tmp_test\fused_by_python.bin
      Get-FileHash 对比 armor_payload.fused.bin（Windows PS1 产物）
字面输出:
  python = 1D63ED0A88EEF1A7DBD3B9222925E108AFA1F5DBA8C6A2E954610F9B87FB0171  (16892293 B)
  ps1bin = 1D63ED0A88EEF1A7DBD3B9222925E108AFA1F5DBA8C6A2E954610F9B87FB0171
  BYTE-EQUAL
备注: 现役 armor_payload.bin (840FE6D2..) 是新一代融合弹（3.16.3 线），
      armor_payload.fused.bin (1D63ED0A..) 为旧线产物——本节证明的是融合算法移植等价，
      部署一律以现役弹 840FE6D2.. 为准。
      对已融合弹体跑 fuse_round.py 会报 "needle absent"（官方常量已被替换）——预期行为。
